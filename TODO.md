# PipelinePro acceptance criteria

- Build a sales tracking dashboard for the CRM “PipelinePro” that visualizes revenue trends, deals in progress, and rep performance.
- Include KPI cards for Monthly Revenue, Win Rate, and Deals Closed with concise comparison context.
- Include a sales funnel chart showing deal progression across pipeline stages.
- Include a revenue-over-time chart for sales trends with selectable periods.
- Include an active deals table with deal, account, value, owner, stage/status, and timing information.
- Include a rep leaderboard that ranks sales representatives by clear performance metrics.
- Include persistent sidebar navigation for the dashboard’s primary CRM sections.
- Keep the visual system focused on black and white because the CRM supports clothing branding; use restrained soft gradients, rounded corners, and a little glassmorphism.
- Keep each screen compact, complete, space-efficient, and easy for the operator to use.
- Use the attached Mera Integrated System Flow image as workflow context, with operational cues inspired by its staged handoffs.
